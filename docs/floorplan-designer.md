# 户型设计师功能清单

业主在同一套住宅的多个命名方案间尝试布局。进入方案后通过 DSH 会话建模，侧栏显示最新接受的模型。模型、工程和素材保存在本机。

| 功能 | 验收情景 |
| --- | --- |
| 方案列表 | 打开工作台先看名称，点选后进入方案。可返回列表、新建、重命名、复制。已有历史快照也可独立打开。 |
| 图片或文字建模 | 在会话附上普通户型图，或描述布局。使用支持识图的模型时，专家能收到本轮图片。尺寸缺失时给出估算依据，收到实测数据后更新。 |
| 对话改图 | 专家读到当前方案和各层源码。用户指定对象或楼层后，专家提交修改，在主会话接受后写入；拒绝则保留原模型。 |
| 本地源码模型 | 每层用米制的 Three.js 函数描述几何和材质。构建器支持分组、网格、常用几何体、材质和变换，技能中附有可运行示例。已有结构化墙、门窗与家具仍可显示。 |
| 多层住宅 | 平层、复式、别墅共用方案结构，按各层标高组合。可在会话修改本层、增加楼层或调整层间关系。 |
| 画布查看 | 平面使用正交俯视，立体视图可拖动旋转。两种视图可平移、缩放、适应画布。可看单层，立体视图也可看整栋。 |
| 撤销 | 撤销本方案最近一次已保存的模型修改。返回列表或重启后仍可撤销；复制出的方案独立编辑。 |
| 模型交换 | 方案列表支持导入和导出 iHome 工程与自包含 GLB。工程包含当前楼层源码和引用素材，可导入后继续对话修改；GLB 供通用三维查看器使用。 |
| 布局评审与决定 | 在对话讨论动线和需求，比较命名方案。采纳的方案可以记录为装修决定，待量尺寸可交给任务待办助理。 |
| 已有参考底图 | 打开原先保存的方案，平面视图可显示已校准的底图，专家也可以读取其图像和尺度。 |
