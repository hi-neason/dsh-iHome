# 户型设计师功能清单

业主在同一套房中尝试多个设计方案。平面图与 Three.js 立体图共享以米为单位的可编辑模型，平层、复式和别墅均可从空白或业主提供的资料开始。模型与素材保存在本机。

| 进度 | 功能 | 验收情景 |
| --- | --- | --- |
| ☑ | 1. 本地模型与楼层 | 打开户型工作台，从空白一层开始，增设二层或地下层，设置各层标高和层高；重开后草稿仍在。 |
| ☑ | 2. 平面编辑 | 在选定楼层画墙，设置门窗、房间、家具、楼梯和洞口；点击对象修改尺寸与位置，撤销草稿改动。 |
| ☑ | 3. 立体模型 | 从相同草稿切换到可旋转缩放的 Three.js 模型，可看整栋或单层，检查门窗洞口与跨层楼梯。 |
| ☑ | 4. 方案与版本 | 新建、复制当前或历史版本继续画，保存有名称的快照，打开比较，再回到草稿；历史版本独立保留。 |
| ☑ | 5. 对话建模 | 在专家团或用 /户型设计师 描述房屋、点名选中的对象，生成几何或局部改图；可见变更在主会话确认，工作台加载最新模型。 |
| ☑ | 6. 原始户型图与比例 | 导入本地或家庭档案中的平面图片作为各层底图，按一段已知长度校准，在底图上描绘；专家可结合用户附图和尺度识图。 |
| ☑ | 7. 通用 3D 交换 | 把本地自包含 GLB 放入指定楼层，调整位置、朝向、大小；动态加载并导出整栋可分享的 GLB。 |
| ☑ | 8. 可编辑工程交换 | 导出包含草稿、历史版本和引用素材的工程文件；导入为独立方案，可继续编辑原有墙、门窗和家具。 |
| ☑ | 9. 布局评审与决定 | 根据家人、房间需求和实际几何复核动线与使用冲突、讨论备选、比较前后版；把决定入档、把补量事项带给任务助理。 |
| ☑ | 10. 在对话中读取已校准底图 | 指定方案、版本和楼层，户型设计师能读到对应原图及其米制比例，再讨论门窗和墙体位置。 |

每项以独立提交发布。GLB 中的外部网格保留其原有几何，iHome 工程文件同时保留墙、门窗等对象之间的编辑关系。
