# 选商核价分析师

业主按装修公司保存设计图、报价单和合同，既能请分析师审核一家公司，也能指定多家公司对比。每个价格判断要能追到具体版本和原文位置，网上评价另附来源和门店归属。

## 从公司档案验收

| 入口 | 操作 | 可核对的结果 |
| --- | --- | --- |
| 公司档案 → 公司资料 | 为甲乙两家公司上传同名原件，再给甲上传修订版。 | 两家公司各有自己的资料清单，甲的旧版与新版均可打开、下载，重新进入会话仍可按版本读取。停用新版后，新审核默认选取仍有效的旧版；退出的公司可在「已退出」中找回。 |
| 公司档案 → 网上评价 | 填写城市、门店，发送调研请求，确认归档。 | 展示来源类型、链接、原文摘录、查阅日期、归属与局限。只有商家宣传或没有可读网页时如实记录。 |
| 公司档案 → 公司审核 | 选择图纸、报价和合同版本并发送。例如图纸写 24㎡，报价只列 17㎡、100 元/㎡。 | 指出少计的 7㎡、按该书面单价相差的 700 元，引用对应位置，并说明合同如何约定增项及价格判断还缺哪些同条件样本。 |
| 公司对比 | 指定两家及各自版本，保留一项仅一家有报价的工作。 | 分别比较设计覆盖、范围、价款、合同与口碑。缺失费用保留未知，只有同条件分项才进入可比小计。确认后可重开报告，看见当时的依据。 |

公司的文件原件、版本与归档报告保存在本机。AI 审核通过 DSH 配置的模型运行。网上评价使用 DSH 的搜索及网页读取服务。

## 能力与验收

| 功能 | 业主操作 | 可以核对的结果 |
| --- | --- | --- |
| 1. 候选与考察 | 录入两家团队、城市、承包内容、考察及资质证据。 | 重新打开仍可看到和编辑同一份本地档案。 |
| 2. 报价版本 | 逐行录入或粘贴表格，保存文件出处、分项、数量单价及原报金额。 | 基于旧版另存修订版，仍可打开两个版本。 |
| 3. 同口径比价 | 为不同团队选择版本，对齐共同项目。 | 可比项目显示差额；计量、工程范围、规格或供应方式不同的项目标明原因；漏报保留未知。 |
| 4. 金额与参考价核查 | 核对乘积、分项汇总与商家总额，录入有城市、日期、规格与来源的参考价。 | 可追溯差异的原始数字及出处；条件不匹配时保留待核实状态。 |
| 5. 合同与澄清 | 对照合同核对付款、工期、材料替换、增项、验收及保修，记录问题、商家答复及证据。 | 打开指定报价即可区分待确认和有书面答复的项目，后来版本不覆盖原答复。 |
| 6. 选商决定与报告 | 选定具体报价版本，写明取舍，并导出给家人或签约前核对。 | 决定关联选商时的版本，报告列明候选、金额、可比差异和待解决的问题。 |
| 7. 专家团对话 | 从头像或斜杠选中分析师，询问报价或提出修改。 | 专家只能读取和建议，主会话展示改动，业主接受后才写入；拒绝及版本冲突保留原数据。 |
| 8. 业主询价底稿 | 按图纸或业主要求独立登记必报项目，例如清运，再导入各家的报价。 | 即使每家都没报，比较与单家核查仍会显示这项缺口；每家都报了相同的错误规格时也能追到要求出处。 |
| 9. 阅读本轮报价原件 | 在原生对话中附报价或合同文件，选分析师审阅。 | TXT、CSV、TSV 可逐行读取，DOCX 保留段落及表格位置，XLSX 保留工作表、单元格地址、公式及已有缓存。macOS 使用系统 PDFKit 读取 PDF 指定页，其他平台使用 DSH 本地 Office 服务。需要看 Word 或 Excel 版式时也可请求页图。原件目录、未读范围与读取失败均可辨别。 |

## 用一组数字验收

例如，两家对同一项墙漆都报 2 平方米，规格、工艺及承包范围相同，单价分别为 30 和 33 元。预期可比合价分别为 60 和 66 元，差额 6 元。把「建筑垃圾清运」写入业主底稿且两家都留空，预期报告同时列出两家未报价和底稿出处。若另一项数量为 2、单价为 15、原列合价为 32，核价页应提示计算值 30 和书面值 32，原始报价仍保留 32。选择其中一个版本，填写理由，预览并确认后导出报告。

所有项目数据在本地 DSH 保存。参考单价由业主提供或依据已取得的材料登记。缺少城市、规格、承包口径或价格依据时，交给商家澄清。商家线索、资质材料和合同条款的最终核验由业主及相应专业人员完成。

## 指定公司的网上评价调研

[土巴兔的评价说明](https://www.to8to.com/help/?id=11)列出设计、水电、泥木、油漆和施工质量等阶段。[Houzz 的评价规则](https://pro.houzz.com/pro-help/r/review-policy)要求评价来自实际客户体验、披露收取的优惠或报酬，并限定同一家庭对同一项目提交一次评价。两者都是平台规则，不能证明某一家公司的履约情况。公司档案的「网上评价」按城市和门店打开原文，分别列出业主、商家、官方及其他来源，保留摘录、日期、归属判断及未能核实的部分。业主确认后归档，再次调研会保留历次结果。
