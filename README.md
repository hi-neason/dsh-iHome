# iHome

iHome 是面向智能装修与家居的 DeepSeek Harness 插件。首页可以按装修阶段选择专家，点击角色头像即可进入专属会话。设计阶段由需求分析师和户型设计师负责，选商阶段由选商核价分析师负责，施工阶段由选材采购买手和施工项目经理负责，验收、入住阶段分别由验收监理和入住规划师负责。装修知识助手、文档资料员和任务待办助理在所有阶段均可使用。界面跟随系统明暗外观，首页使用随插件打包的 Three.js 绘制微缩装修工作室。十位专家各有岗位和动作，点击场景中的人物或下方名片可进入专属会话。动画支持暂停并遵循系统减少动态效果设置，无法启动 WebGL 时显示工作室静态图。开发基准为桌面端 `0.2.2-rc.5`。

## 从源码构建

在仓库根目录使用 Node.js 22.14 或更新的 22.x 版本和 npm 构建、验证插件。

```sh
npm ci
npm test
npm run build
```

构建会先检查 TypeScript 类型，再将宿主和客户端入口输出到 `dist/`。React 由桌面端提供。

## 在桌面端加载

1. 构建完成后，在仓库根目录运行 `pwd`，复制仓库的绝对路径。安装目录应包含 `package.json`。
2. 在 DeepSeek Harness 打开 **插件 → 添加插件 → 安装第三方插件**，将路径粘贴到「包名或地址」，确认安装。
3. 在「已安装」中打开 **iHome**，确认组件显示「运行中」。本地开发时，重新构建后可在这里停用并重新启用 iHome 组件，加载更新后的宿主代码。

点击左侧 **iHome** 始终回到装修专家团首页。首次打开时，插件会在当前用户的主目录创建 `~/iHome工作区`，并将其注册为名为 **iHome工作区** 的 DSH 工作区。首次选择一位专家会创建对应的原生会话，再次进入可继续上次的对话。已有模块会话从对应角色入口打开时会沿用原会话，并将旧版默认标题更新为角色名。用户自定义标题会保留。

在 DSH 0.2.2-rc.5 中，首次发送消息之前，左侧会话树将当前空会话显示为「新会话」，窗口标题和右侧工作台显示角色名。发送后，该会话会以角色名列入历史。在此工作区手动点击 DSH 的「新会话」时，宿主可能复用一条已有的空会话。要继续与指定专家对话，请从首页或工作台的「切换专家」进入。

在桌面宽屏上，中间是 DeepSeek 原生对话，右侧是该专家的 iHome 工作台。可拖动分隔线调整宽度，或收起右栏。也可从右栏的工具目录打开 iHome 工作台。在工作台点击「带到对话」等操作，会把相关内容追加到当前会话的输入框，由你编辑并发送。

## 家庭档案

打开 **需求分析师 → 居住需求**。可以直接记下一条需求，在同一张表单中添加家人和「房间或区域」，也可以从一件生活里的烦恼开始对话。每条正式需求至少关联一位家人和一个房间或区域，可关联多个空间，也可按任一空间筛选。AI 整理需求、生活事实或量房尺寸后，会在当前对话列出改动。选择「接受」即保存到本机，工作台自动刷新；选择「不接受」或填写修改意见可继续讨论。已入档的单条需求可以带入设计与选材讨论。

**居住需求** 页分为「需求」和「决定」两个标签。「需求」展示居住需求表和筛选条件。「决定」展示选定的做法、关联需求、选择理由和依据资料。更新决定时会保留旧版本，可回看当时的取舍。

**家人与房屋** 分为「家人」「房间或区域」。家人表可填写称呼、性别、年龄、居住时间和居住需求，超过 20 字的需求可展开查看全文。书房、玄关、阅读区等空间都可以直接添加。每个空间占一行，列出关联需求和家人。旧档案中记录在子区域的需求会自动归到所属房间。已有生活资料和尺寸可分别在对应表格下方展开查看。团队共用这份家庭档案。

数据通过 DSH 宿主的 `storageDomain` 保存在本机。默认 JSON 后端的档案域是 `ihome_archive`，附件由宿主保留原件。手动录入、查找和导入资料均可离线使用。AI 对话使用 DSH 已配置的模型，家庭档案的读取和提案工具仅在 **iHome工作区** 的会话中启用。

在 **需求分析师 → 基础资料** 可以保存原始户型图、量房资料、交付照片与物业规定。基础资料也会出现在 **通用助手 → 文档资料员**。旧档案中未分类的附件按原始资料显示。

文档资料员的工作台支持将本机文件按装修阶段归档，区分文档和物料资料，填写来源、备注并关联房间或区域。可以搜索、编辑或下载原件，也可以在对话中按关键词、阶段或类型查找归档记录。对话检索返回资料名称等归档信息，需要阅读正文时请提供原件。

## 业主待办

打开 **通用助手 → 任务待办助理**，可以记下待办、填写备注和计划日期。日期可以留空，之后从「未排期」找到任务再安排。月历标出每天的任务数，点击日期可查看当天的清单。勾选任务即可标记完成，再点一次可重新打开。工作台显示整体完成进度和已逾期的待办数量。

也可以在专属会话中说「周六去现场确认厨房插座位置」，或问「这周还有哪些事没做」。助理可以查询已保存的任务，并在对话中请你确认新增、改期、完成或删除操作。任务保存在本机的 `ihome_tasks` 数据域。

## 开发入口

| 文件 | 用途 |
| --- | --- |
| `package.json` | 声明包名 `dsh-ihome`、兼容版本范围和组合包入口 |
| `cordis.patch.yml` | 将组件 `ihome` 加入宿主配置 |
| `src/index.ts` | 宿主插件的 Cordis 生命周期入口，注册本地档案接口和 AI 工具 |
| `src/ihome-workspace.ts` | 专用工作区、持久化模块会话索引及会话上下文 |
| `src/client.tsx`、`src/ModuleWorkbench.tsx` | 首页入口、原生会话导航、右侧工作台与对话草稿 |
| `src/Home.tsx`、`src/ExpertExhibit.tsx` | 首页导航、住宅主视觉与动效 |
| `src/modules.ts`、`src/ModuleDetail.tsx` | 角色与阶段目录、准备清单和对话入口 |
| `src/RoomPreview.tsx`、`src/Knowledge.tsx` | 户型设计师示例和装修知识指南 |
| `scripts/build.mjs` | 将 TSX 打包为桌面端模块加载器使用的客户端格式 |
| `locale/en.json`、`locale/zh.json` | 设置插件管理页的英文和中文名称与简介 |
