# iHome

iHome 是面向智能装修与家居的 DeepSeek Harness 插件。首页提供家庭档案、装修知识、设计、选材采购、选商报价与合同、预算、施工现场、验收交付与保修八个入口。界面跟随系统明暗外观，首页分六步展示同一间房从毛坯到布置完成的过程，每步 1 秒，每轮 6 秒，支持暂停。开启系统的减少动态效果后，首页显示装修完成的静态画面。开发基准为桌面端 `0.2.2-rc.5`。

## 从源码构建

在仓库根目录使用 Node.js 22.14 或更新的 22.x 版本和 npm 构建、验证插件。

```sh
npm ci
npm test
npm run build
```

构建会先检查 TypeScript 类型，再将宿主和客户端入口输出到 `dist/`。React 由桌面端提供。

## 在桌面端加载

1. 构建完成后，在仓库根目录运行 `pwd`，复制仓库的绝对路径。安装目录应包含 `package.json`。
2. 在 DeepSeek Harness 打开 **插件 → 添加插件 → 安装第三方插件**，将路径粘贴到「包名或地址」，确认安装。
3. 在「已安装」中打开 **iHome**，确认组件显示「运行中」。本地开发时，重新构建后可在这里停用并重新启用 iHome 组件，加载更新后的宿主代码。

点击左侧 **iHome** 始终回到八模块首页。首次打开时，插件会在当前用户的主目录创建 `~/iHome工作区`，并将其注册为名为 **iHome工作区** 的 DSH 工作区。首次选择某个模块会创建对应的原生会话，再次进入可继续上次的对话。

在 DSH 0.2.2-rc.5 中，首次发送消息之前，左侧会话树将当前空会话显示为「新会话」，窗口标题和右侧工作台显示模块名。发送后，该会话会以模块名列入历史。在此工作区手动点击 DSH 的「新会话」时，宿主可能复用一条已有的空会话。要继续指定模块，请从首页或工作台的「切换模块」进入。

在桌面宽屏上，中间是 DeepSeek 原生对话，右侧是该模块的 iHome 工作台。可拖动分隔线调整宽度，或收起右栏。也可从右栏的工具目录打开 iHome 工作台。在工作台点击「带到对话」等操作，会把相关内容追加到当前会话的输入框，由你编辑并发送。

## 家庭档案

打开 **家庭档案库 → 居住需求**。可以直接记下一条需求，在同一张表单中添加家人和「房间 · 区域」，也可以从一件生活里的烦恼开始对话。每条正式需求至少关联一位家人和一个具体区域，支持多选和跨房间筛选。AI 整理需求、生活事实或量房尺寸后，会在当前对话列出改动。选择「接受」即保存到本机，工作台自动刷新；选择「不接受」或填写修改意见可继续讨论。已入档的单条需求可以带入设计与选材讨论。

**居住需求** 页分为「需求」和「决定」两个标签。「需求」展示居住需求表和筛选条件。「决定」展示选定的做法、关联需求、选择理由和依据资料。更新决定时会保留旧版本，可回看当时的取舍。

**家人与房屋** 分为「家人」「房间与区域」。家人表可填写称呼、性别、年龄、居住时间和居住需求，超过 20 字的需求可展开查看全文。区域行列出关联需求和涉及的家人，房间行汇总下属区域并去重。已有生活资料和尺寸可分别在对应表格下方展开查看。八个模块共用这份家庭档案。

数据通过 DSH 宿主的 `storageDomain` 保存在本机。默认 JSON 后端的档案域是 `ihome_archive`，附件由宿主保留原件。手动录入、筛选、导入和导出均可离线使用。AI 对话使用 DSH 已配置的模型，家庭档案的读取和提案工具仅在 **iHome工作区** 的会话中启用。

在 **资料与备份** 可以导入图纸、照片或 PDF，也可以导出包含档案与附件原件的 `.ihome` 文件。恢复前会显示备份范围，确认后替换当前家庭档案。若旧版档案含有多套房，工作台使用第一套，其余资料随整份档案保留和备份。

## 开发入口

| 文件 | 用途 |
| --- | --- |
| `package.json` | 声明包名 `dsh-ihome`、兼容版本范围和组合包入口 |
| `cordis.patch.yml` | 将组件 `ihome` 加入宿主配置 |
| `src/index.ts` | 宿主插件的 Cordis 生命周期入口，注册本地档案接口和 AI 工具 |
| `src/ihome-workspace.ts` | 专用工作区、持久化模块会话索引及会话上下文 |
| `src/client.tsx`、`src/ModuleWorkbench.tsx` | 首页入口、原生会话导航、右侧工作台与对话草稿 |
| `src/Home.tsx`、`src/HouseExhibit.tsx` | 首页导航、住宅主视觉与动效 |
| `src/modules.ts`、`src/ModuleDetail.tsx` | 模块目录、准备清单和对话入口 |
| `src/RoomPreview.tsx`、`src/Knowledge.tsx` | 设计工作室示例和装修知识指南 |
| `scripts/build.mjs` | 将 TSX 打包为桌面端模块加载器使用的客户端格式 |
| `locale/en.json`、`locale/zh.json` | 设置插件管理页的英文和中文名称与简介 |
