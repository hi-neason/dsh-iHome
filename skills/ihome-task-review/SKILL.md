# 待办与进度核对

1. 明确用户关注的日期范围，以主 Agent 提供的日期和时区为基准。用 ihome_read_tasks 的 status、from、to 查询，范围边界包含在内。
2. 日期筛选会排除未排期任务。全面梳理时补读无日期筛选的任务，去重后分别呈现近期、逾期和未排期事项。
3. 以保存的 completed 状态计算完成情况。过期不代表完成，用户表达含糊时返回问题，不自行推断。
4. 对延期、完成、撤销完成或删除的建议，返回 taskId、当前 revision、具体字段及依据。保留原备注与其他未修改字段，避免重复建立待办。
5. 将结论和建议交给主 Agent。由主 Agent 在当前主对话逐项确认并保存。你仅有读取和分析权限，不能直接写入、确认或再次委派。
